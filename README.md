# AMD plus — «Характер в деталях»

Локальная версия интерфейса нового сайта. Оригинальные предыдущие концепции сохранены в `design/` и не заменены.

## Просмотр

Из корневой папки проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/site/ . Обычная сборка и установка npm-пакетов не требуются. Изображения и шрифты размещены локально в `assets/`.

## Интерфейс

Сайт состоит из короткой главной и самостоятельных адресуемых разделов:

- `index.html` — главная из трёх экранов: автомобильная сцена, один разобранный кейс «до / после», три входа по задаче и короткий контактный блок.
- `services.html` — каталог из 18 услуг с поиском и фильтрами; якоря `#body`, `#interior`, `#care` сразу выбирают направление.
- `service.html?id=<услуга>` — отдельная страница услуги: описание, особенности, переход к оценке и ссылка на исходный сайт.
- `works.html` — работы ателье; `case.html?work=prado|bmw|retro` — разбор конкретной работы с переключением отдельных кадров «до / после».
- `atelier.html` — об ателье и материалах, ссылки на видео и 3D-тур.
- `contacts.html` — адрес, часы, телефон, Telegram, маршрут и ссылки на гарантию, оплату, выезд специалиста.

Общие элементы — поиск, окно оценки по фото, мобильное меню и анимации — работают на всех страницах. При `prefers-reduced-motion` движение отключается, контент остаётся доступным без JavaScript.

## Границы реализации

Это фронтенд, не опубликованный публичный сервис. Не подключены серверная отправка заявки, загрузка фотографий, CRM, аналитика, платежи или собственная картография. Интерфейс не сообщает об успешной отправке, если её не было. Введённые описания не сохраняются автоматически и не отправляются в фоне.

Часть разделов пока открывает соответствующие страницы https://amdplus.ru/ . Цены, отзывы и обязательства не выдумываются.

Фотографии «до / после» сняты с различающихся ракурсов: используем переключение отдельных кадров, не имитацию бесшовного восстановления.
